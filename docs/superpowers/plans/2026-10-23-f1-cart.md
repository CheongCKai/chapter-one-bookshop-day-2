## Global constraints

No new dependency, framework, build tool, stylesheet or persistent state.
No checkout, orders, stock deduction, accounts, authentication, sessions, search
or low-stock cue. Positive safe integer quantities only; zero is invalid.
Repeated adds merge and combined quantity cannot exceed stock. Titles/prices
come from catalogue; calculate totals in integer cents. Opaque UUID IDs,
defensive snapshots and reset clearing carts. JSON errors use `{ error }`:
400 invalid shape/quantity/stock; 404 missing resource. Escape dynamic HTML.

Every phase runs `npm test`, `npm run typecheck`, `npm run lint`. Final review
adds `npm run format:check` and `npm audit --audit-level=high`. The baseline
audit fails: preserve this result, never suppress it or claim final READY.
Keep original tests intact. Record actual RED before implementation.

## Shared contracts

Types in src/types.ts:

```typescript
export interface CartItem {
  bookId: string;
  title: string;
  unitPrice: number;
  quantity: number;
  lineTotal: number;
}
export interface Cart {
  cartId: string;
  items: CartItem[];
  total: number;
}
```

Store methods introduced incrementally: `createCart(): Cart`,
`getCart(cartId: string): Cart | undefined`,
`addCartItem(cartId: string, bookId: string, quantity: number): Cart`,
`updateCartItem(cartId: string, bookId: string, quantity: number): Cart`,
`removeCartItem(cartId: string, bookId: string): void`.

Use a typed expected error carrying 400/404, translated to JSON in the router.
Route validates shape/quantity before mutation; store rechecks resources and
prospective stock. Do not expose unexpected exception details. POST create
returns 201; GET, add and PATCH return 200; DELETE returns 204 with no body.
